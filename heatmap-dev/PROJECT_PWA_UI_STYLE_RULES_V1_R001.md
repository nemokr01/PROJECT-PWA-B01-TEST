## 3. 카드·구획·배치 재사용

- 일반 자산 카드 `.asset-card`: 흰색 바탕, 테두리 `1px solid #dce8f3`, 모서리 `15px`, 부드러운 그림자. 평가/전일 대비는 부호별 배경을 별도 적용.
- 시장지수 카드 `.index-card`: 흰색 바탕, 테두리 `1px solid #e4ebf3`, 기본 모서리 `12px`, 모바일 `9px`. 현재 5개가 한 줄에 보이는 폭 계산 `calc((100% - 20px)/5)`, 카드 간격 `5px`; 스크롤/위치 표시 유지.
- 히트맵: 평가금액 비례 면적, 부호·색상 범례 병행, 최소 타일 크기/좁은 화면 처리 등은 JS·CSS 원본 및 별도 F01 계약을 따른다. 종목명/수익률/비중은 타일 크기에 따라 단계별 축소.
- 브리핑: 제목·예시·기준시각·설명·자세히 보기·하단 내비 구획 유지.
- 모바일 대응은 `@media(max-width:600px)`, `@media(max-width:480px)`, 세로 방향 및 `max-height:650px` 등 원본의 모든 미디어 쿼리 확인. 위 숫자를 모든 화면에 고정하지 않는다.
- Galaxy S25 Ultra 실기기에서 최종 폰트 렌더링·줄바꿈·대비·크기 검증은 **미확인**.

## 4. 새 기능 추가 규칙

1. 먼저 기존 컴포넌트 선택자·글꼴·크기·색상·여백·테두리·모서리·그림자·반응형을 재사용한다.
2. 새 제목은 기존 동급 제목과, 새 금액은 기존 동급 금액과, 새 보조문구는 기존 보조문구와 시각적 위계를 맞춘다.
3. 상승 빨강/하락 파랑/보합 중립, 지수카드 흰 배경, 웜 아이보리 전체 배경을 기본으로 한다. 사용자 별도 승인 없이는 반전하지 않는다.
4. 새 기능에 고유 스타일이 필요하면 기존 UI와의 차이·이유를 기록하고 승인 범위에서만 반영한다.
5. 코드 변경 시 이 문서의 개정본을 **새 파일명**으로 발행한다(`V1_R002` 등). 원본 덮어쓰기·과거 Evidence 변경 금지.
6. CSS 원본에 중복·상충 규칙이 있으므로 정리/토큰화는 별도 변경 승인 후 수행. 문서 생성만으로 기존 UI 코드를 변경하지 않는다.
